# **App Name**: MithilaCab

## Core Features:

- User Registration and Authentication: Secure user registration and login system using OTP verification and persistent sessions.
- Ride Booking: Enable users to book rides by selecting pickup and destination locations.
- Fare Calculation: Automatically calculate ride fare based on distance estimation.
- Driver Assignment: Automatically assign available drivers to ride requests.
- Real-Time Ride Tracking: Provide real-time updates and tracking of rides on a map.
- Ride Completion and Rating: Allow drivers to mark rides as complete, and users to rate the ride.
- Ride History: Store and retrieve ride history for each user including driver information, fare amount, and timestamps.

## Style Guidelines:

- Primary color: Deep sky blue (#439AFF), conveying trust and reliability, especially suitable for mapping applications
- Background color: Light gray (#F0F4F7), offering a clean, neutral backdrop that enhances readability
- Accent color: Indigo (#6649B8), which contrasts vividly and emphasizes key interactive elements.
- Headline font: 'Poppins', a geometric sans-serif font that communicates a contemporary and avant-garde look.
- Body font: 'PT Sans', a humanist sans-serif font to promote a modern and accessible feel.
- Use clear, consistent icons for navigation and ride status, such as location markers and car symbols.
- Maintain a clean and intuitive layout for booking, tracking, and viewing ride history.
